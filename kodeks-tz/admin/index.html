Первая настройка

Делается один раз. Нужен ключ доступа GitHub к репозиторию сайта:

  1. github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → репозиторий сайта.
  3. Permissions → Contents: Read and write. Срок действия — на ваше усмотрение.
  4. Скопируйте ключ и вставьте ниже вместе с паролем для входа в админку.

Ключ сохраняется на сайте только в зашифрованном виде. Расшифровать его можно только паролем.

Уволился сотрудник — замените имя, должность и фото в его карточке или удалите карточку. Нажмите «Сохранить на сайт». Изменения появятся через 1–2 минуты.
